A modern, responsive, and interactive personal portfolio website designed for **Kunal Chaurasiya**, a Frontend Developer, Web Designer, and B.Sc. Computer Science student at the University of Delhi. 

The portfolio showcases projects, skills, academic achievements, credentials, and experience with a polished glassmorphic UI, custom dark/light theme toggle, dynamic project filtering, and smooth interactive animations.

---

## ✨ Features

- 🌓 **Dark & Light Mode Toggle**: System-aware theme toggle with instant transitions and `localStorage` persistence.
- 🎨 **Glassmorphism & Micro-animations**: Modern aesthetic with dynamic cursor glow background, subtle hover effects, and sleek gradient accents.
- 💻 **Dynamic Project Showcase**: Interactive category filtering (Web Dev, Python/AI, All) with modal popups for deep-dive project details and direct GitHub repository links.
- 📜 **Credentials & Credentials Showcase**: Interactive gallery displaying verified certifications and academic credentials with preview modals.
- 📱 **Fully Responsive Layout**: Built mobile-first using Tailwind CSS, ensuring seamless experiences across desktops, tablets, and mobile devices.
- 🚀 **Performance & SEO Optimized**: Clean semantic HTML, Google Fonts (*Outfit* & *Syne*), lightweight assets, and structured metadata.

## 🚀 Getting Started

### Prerequisites

No complex build pipeline or package manager is required! You only need a modern web browser.

### Running Locally

1. **Clone the Repository**
   ```bash
   git clone https://github.com/kunalchaurasiya01/Portfolio.git
   cd Portfolio
   ```

2. **Open in Browser**
   - Double-click `index.html` to open it directly in your browser, or
   - Use VS Code extension **Live Server** for real-time reload (Right-click `index.html` → **Open with Live Server**).
   - Alternatively, serve via `npx`:
     ```bash
     npx serve .
     ```
